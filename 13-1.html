Font Awesome 图标

本页图标全部以「字体」形式渲染：图标 = 一个 icon font 文件中的字形，用 CSS 像操作文字一样控制它们。

原理：引入 cdn/fontawesome/css/all.min.css 后， CSS 通过 @font-face 加载 cdn/fontawesome/webfonts/ 下的字体文件 （fa-solid-900 / fa-regular-400 / fa-brands-400）， 再用 <i class="fa-solid fa-house"></i> 的 ::before 伪元素写入 content 字符码， 浏览器便从图标字体中取出对应字形绘制出来。因此颜色、大小、阴影、旋转都可以用普通 CSS 控制。

写法与特性

① 基本写法：样式前缀决定使用哪套字体（solid / regular / brands）。

<i class="fa-solid fa-house"></i> <i class="fa-regular fa-heart"></i> <i class="fa-brands fa-github"></i>

② 既然只是「文字」，就能直接用 CSS 设置颜色、尺寸、旋转和动画。

默认 变色 2 倍 旋转 动画
<i class="fa-solid fa-bolt fa-2x fa-rotate-90 fa-beat" style="color:#38a169;"></i>

③ 字体图标的优点：体积小、可无损缩放、能用 CSS 一次性改色；缺点：一次只能显示一个字形、无法单独改某条线、必须加载字体文件（否则出现「豆腐块」）。
