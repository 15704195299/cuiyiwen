Lucide 图标

本页图标全部以「SVG 矢量图形」形式渲染：每个图标就是一段可直接写在 HTML 里的 <svg> 代码，文件保存在 cdn/lucide/icons/。

原理：Lucide 把每个图标发布成独立的 .svg 文件 （本目录 cdn/lucide/icons/，共 48 个）。 SVG 是 HTML 支持的图形标签，可以直接内联到页面里： stroke="currentColor" 让线条颜色继承文字颜色， stroke-width / stroke-linecap 控制线条粗细与端点样式， width / height 控制尺寸——它不是字体，不依赖任何字体文件。

写法与特性

① 一个图标就是一段 SVG 源码（以下为 cdn/lucide/icons/home.svg 的内容）：

<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"> <path d="M15 21v-8a1 1 0 0 0-1-1h-4a1 1 ..." /> <path d="M3 10a2 2 0 0 1 .709-1.528l7-5.999a2 ..." /> </svg>

② 因为是图形不是文字，样式要写在 SVG 自身的属性上（或用 CSS 选择器选中它）：

默认 改色 加粗 3.5 放大 48px
<svg stroke="#e53e3e" stroke-width="3.5" width="48" height="48" ...> ... </svg>

③ 也可以不内联，直接把 cdn 目录里的 svg 当作图片引用（见下一节）；两种方式都不需要字体文件、不需要 JavaScript。

字体图标 vs SVG 图标

对比项 字体图标（Font Awesome / 13-1） SVG 图标（Lucide / 13-2）
本质 icon font 里的一个字形，由 ::before 的 content 显示 一段图形代码 <svg>，由浏览器直接绘制
着色 整枚图标只能一个颜色（继承文字 color） 可用 stroke / fill / CSS 单独控制每条路径
依赖 必须下载字体文件，加载失败会变成豆腐块 内联时零额外请求；用 <img> 时只请求 svg 文件
多色图标 不支持 支持（不同 path 不同颜色）
清晰度 矢量，缩放清晰 矢量，缩放清晰
