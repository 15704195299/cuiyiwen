13-3 · 字体图标 iconfont

移动端底部导航（字体图标版）

固定底部 · 全屏宽度 · 5 项等分自适应 · 每项带数字徽章与右上角红点

实现要点

  • 图标来自项目字体 font/iconfont.css，写法是 <i class="iconfont icon-shujia"></i>，字形由 @font-face 渲染（woff2 / woff / ttf）。
  • 5 个图标对应 icon-shujia / icon-faxian1 / icon-shucheng / icon-14 / icon-wode1，分别用于 书架 / 发现 / 书城 / 论坛 / 我的。
  • 导航容器 position: fixed; left:0; right:0; bottom:0; width:100% → 永远钉在屏幕底部且占满整个屏幕宽度。
  • 5 个导航项 flex: 1 1 0; min-width:0 → 无论 320px 手机还是 2560px 桌面，都自动等分成 20%，宽度随屏幕自适应。
  • 每项都有 数字徽章（图标方框右上角 top:4px; right:-6px）和 右上角红点（导航项右上角 top:2px; right:6px），两者上下错开、互不遮挡。
  • padding-bottom: env(safe-area-inset-bottom) 适配 iPhone 底部横条；viewport-fit=cover 才能生效。
  • 正文留了 padding-bottom，滚动时内容不会被固定导航盖住。

结构与关键样式

<link rel="stylesheet" href="./font/iconfont.css">   <!-- @font-face + 图标 class -->

<nav class="cui-tabbar">
  <a class="cui-nav-item" href="#" aria-current="page">
    <span class="cui-dot"></span>                      <!-- 右上角红点 -->
    <span class="cui-icon-box">
      <i class="iconfont icon-shujia"></i>           <!-- 字体图标·书架 -->
      <span class="cui-badge">3</span>                <!-- 数字徽章 -->
    </span>
    <span class="cui-label">书架</span>
  </a>
  ... 5 项：书架(icon-shujia) / 发现(icon-faxian1) / 书城(icon-shucheng)
          / 论坛(icon-14) / 我的(icon-wode1)
</nav>

.cui-tabbar   { position: fixed; left:0; right:0; bottom:0;
                width: 100%; max-width: none; display: flex;
                padding-bottom: env(safe-area-inset-bottom); }
.cui-nav-item { flex: 1 1 0; min-width: 0; }    /* 5 等分、自适应任意屏宽 */
.cui-nav-icon { font-size: 34px; }              /* 图标大小用 font-size 控制 */
.cui-badge    { position:absolute; top:4px; right:-6px;
                background:#ff7a1a; border-radius:11px; }
.cui-dot      { position:absolute; top:2px; right:6px;
                width:9px; height:9px; border-radius:50%; background:#ff3b30; }
