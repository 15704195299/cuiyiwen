13-4 · SVG 矢量图标

移动端底部导航（SVG 版）

固定底部 · 全屏宽度 · 5 项等分自适应 · 每项带数字徽章与右上角红点 · 零字体、零 JS

实现要点

  • 图标数据同样来自 font/ 目录：把 iconfont.js 中导出的 5 个 <symbol>（icon-shujia / icon-faxian1 / icon-shucheng / icon-14 / icon-wode1）当作 SVG 源码内联到页面顶部，组成雪碧图（本身宽高为 0，不占位置）。
  • 5 项导航分别对应 书架 / 发现 / 书城 / 论坛 / 我的，用 <svg><use href="#icon-shujia"></svg> 复用 symbol，不加载字体、不执行任何 JavaScript。
  • 导出文件里路径写死了 fill="#728BFF" 之类颜色，已删除这些属性，改由 fill: currentColor 继承文字颜色 → 激活/未激活一键换色。
  • 导航容器 position: fixed; left:0; right:0; bottom:0; width:100% → 永远钉在屏幕底部且占满整个屏幕宽度。
  • 5 个导航项 flex: 1 1 0; min-width:0 → 无论 320px 手机还是 2560px 桌面，都自动等分成 20%，宽度随屏幕自适应。
  • 每项都有 数字徽章（图标方框右上角 top:4px; right:-6px）和 右上角红点（导航项右上角 top:2px; right:6px），两者上下错开、互不遮挡；env(safe-area-inset-bottom) 适配 iPhone 底部横条。

结构与关键样式

<svg class="cui-sprite"><symbol id="icon-shujia" viewBox="0 0 1024 1024">...</symbol></svg>  <!-- 雪碧图 -->

<nav class="cui-tabbar">
  <a class="cui-nav-item" href="#" aria-current="page">
    <span class="cui-dot"></span>                      <!-- 右上角红点 -->
    <span class="cui-icon-box">
      <svg class="cui-nav-svg">                        <!-- SVG 图标 -->
        <use href="#icon-shucheng"></use>
      </svg>
      <span class="cui-badge">12</span>               <!-- 数字徽章 -->
    </span>
    <span class="cui-label">书城</span>
  </a>
  ... 5 项：书架(#icon-shujia) / 发现(#icon-faxian1) / 书城(#icon-shucheng)
          / 论坛(#icon-14) / 我的(#icon-wode1)
</nav>

.cui-tabbar   { position: fixed; left:0; right:0; bottom:0;
                width: 100%; max-width: none; display: flex;
                padding-bottom: env(safe-area-inset-bottom); }
.cui-nav-item { flex: 1 1 0; min-width: 0; }    /* 5 等分、自适应任意屏宽 */
.cui-nav-svg  { width:38px; height:38px; fill: currentColor; }
.cui-badge    { position:absolute; top:4px; right:-6px;
                background:#ff7a1a; border-radius:11px; }
.cui-dot      { position:absolute; top:2px; right:6px;
                width:9px; height:9px; border-radius:50%; background:#ff3b30; }
